# Pomodo ⏰

A minimalist Pomodoro timer built with React, TypeScript, and Tailwind CSS.

## Features

- 🎯 Focus, Short Break, and Long Break modes
- ⚡️ Keyboard shortcuts for quick control
- 🎨 Light/Dark theme support
- 📊 Session tracking
- ⚙️ Customizable timer settings
- 💾 Local storage persistence
- 🖥️ Responsive design
- ⌨️ Keyboard-first approach

Visit [pomodo.vercel.app](https://pomodo.vercel.app) to see the live demo.

## Development

```bash
# Clone the repository
git clone https://github.com/ardakaano/pomodo.git
cd pomodo

# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## Keyboard Shortcuts

- Space: Start/Pause timer
- R: Reset timer
- 1/2/3: Switch between modes
- Esc: Toggle settings

## Tech Stack

- React + TypeScript
- Vite for build tooling
- Tailwind CSS for styling
- Local Storage for data persistence
